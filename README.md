Design direction:
- DACH-market credibility: precise, calm, structured, premium, technical, trustworthy.
- Off-white / very light gray background, dark navy/charcoal typography, restrained blue accent.
- Typography: Inter or Geist/Manrope.
- Generous whitespace, subtle borders, refined shadows, minimal gradients.
- No flashy skill bars, no excessive animations, no giant decorative blobs.
- Subtle scroll/reveal animations only.
- Responsive, mobile-first and accessible.
- Strong visual hierarchy and excellent spacing.
- Use lucide icons and shadcn/ui where appropriate.

Structure:
1. Sticky minimal header with Khalil Kadri wordmark, navigation: Über mich, Erfahrung, Projekte, Skills, Kontakt; language toggle DE/EN; prominent "Lebenslauf" button.
2. Hero:
   "Software Engineer · Technical Support Engineer · SAP Developer"
   German supporting copy emphasizing reliable software, enterprise IT and SAP solutions.
   Primary CTA "Projekte ansehen"; secondary CTA "Kontakt aufnehmen".
   Include a compact status line such as "Offen für Positionen in Deutschland & Österreich".
   Right side: sophisticated profile/technical visual area, not a generic stock-photo hero.
3. Trust/technology strip with SAP, Microsoft 365, React, TypeScript, Node.js, Laravel, Docker, WordPress.
4. About section with concise professional summary and 3-4 metrics/cards: 4+ Jahre Entwicklungserfahrung; L2/L3 Support; Bachelor Informatik; Deutsch B2 / Englisch C1.
5. Experience timeline, prioritizing DXC Technology Support Engineer and previous software development/freelance experience. Make it recruiter-readable.
6. Skills organized into categories: Enterprise IT, SAP, Frontend, Backend, Cloud & DevOps, CMS.
7. Projects section with large premium case-study cards. Each card has Problem, Lösung, Tech Stack and an outcome/value-oriented summary. Include links/placeholders for GitHub/demo when appropriate, without inventing URLs.
8. "Warum ich" / value proposition section: combines development + support + enterprise troubleshooting + customer communication.

10. Footer with GitHub, LinkedIn, portfolio, email placeholders only where actual links are known.

The final result should feel like a high-end DACH software engineer / IT consultant portfolio suitable for recruiters at German and Austrian enterprise companies. Do not make it look like a startup landing page or a generic template.
